# Color Palette App

## Descrição

O **Color Palette App** é um aplicativo simples que permite aos usuários explorar diferentes paletas de cores organizadas por temas. Ele oferece categorias de paletas como "Moderno e Limpo", "Calmo e Relaxante", "Quente e Energético", "Elegante e Sofisticado" e "Criativo e Vibrante". Cada paleta contém uma combinação de cores que pode ser usada para projetos de design, desenvolvimento web, ou qualquer outro propósito criativo.

## Funcionalidades

- **Seleção de Paletas**: Os usuários podem escolher entre várias categorias de paletas de cores, com combinações específicas de acordo com o tema selecionado.
- **Visualização Dinâmica**: Ao selecionar uma categoria, as paletas disponíveis são exibidas na tela de forma organizada e visualmente atraente.
- **Estilo Responsivo**: O aplicativo é totalmente responsivo, adaptando-se a diversos tamanhos de tela, desde dispositivos móveis até desktops.
- **Animações Suaves**: Títulos e botões incluem animações suaves para melhorar a experiência do usuário.
- **Botão de Copiar**: Cada paleta inclui um botão que facilita a cópia das cores para uso em outros projetos.

## Como Usar

1. **Selecionar Categoria**: Clique em uma das categorias de paletas de cores exibidas no topo da página.
2. **Explorar Paletas**: As opções de paletas aparecerão abaixo. Cada paleta exibe uma combinação de cores Primária, Secundária, Complementar e Acento.
3. **Copiar Cores**: Para copiar uma cor, clique no botão "Copiar" ao lado da paleta desejada.

## Tecnologias Utilizadas

- **HTML5**: Estrutura da página.
- **CSS3**: Estilos responsivos e animações.
- **JavaScript**: Funcionalidade dinâmica de seleção de paletas.
- **JSON**: Armazenamento das paletas de cores.

## Estrutura do Projeto

- `index.html`: Página principal do aplicativo.
- `css/styles.css`: Arquivo de estilos do aplicativo.
- `js/script.js`: Arquivo JavaScript responsável pelas interações e exibição das paletas.
- `palettes.json`: Dados das paletas de cores organizados por categoria.
